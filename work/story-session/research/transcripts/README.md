# Research transcripts

Five complete original-release English auto-generated caption exports are stored
locally in this directory as `kepler.txt`, `vault.txt`, `contour.txt`, `arize.txt`,
and `quality.txt`. They were extracted from YouTube’s transcript view and read on
October 27, 2026. Source metadata and SHA-256 checksums are in `../sources.json`.

These working copies are ignored by Git and are not embedded in the shareable
presentation. The presentation and presenter guide contain original paraphrases,
analysis, and timestamp links. No audio or video was downloaded or viewed as part
of this research claim. Automatic captions contain errors, including names and
some technical terms; official metadata and organizer readings informed the
paraphrased account. The original captions are preserved without silent edits.
